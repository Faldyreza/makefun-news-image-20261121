A Node 22 program that draws a 1024x1024 newspaper front page summing up the world's news of Saturday, 21 November 2026: COP31 climate talks running into overtime in Antalya, Russian missiles landing in Poland, the mass barrage on Kyiv's bridges, and the Wall Street AI sell-off. It uses a hand-authored stroke font and a pure-stdlib PNG encoder, needs no network at run time, and writes byte-identical output on every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
